- PREBREAK OK = 회사/테마/사이클/뉴스/수급 스토리가 강해 돌파 전 starter 허용
- slight late feel with strong story can still be PREBREAK OK if room is only mildly negative (-2% 이내)
- ENTRY OK = 신규매수 후보
- SMALL SIZE = 신규매수 가능하지만 room이 좁아 비중 축소 필요

- 40DMA = 속도/타이밍 보조 필터 (살짝 아래면 주의, 많이 아래면 한 단계 강등)
- 10DMA = 매우 단기 실행/관리 보조 (랭킹 영향은 거의 없음)
- HOLD ONLY = 이미 들고 있는 사람 관리용, 신규 진입은 비추
- AVOID NEW = 과열 / 점수 문제 / overlay 회피 플래그 등으로 신규 진입 비추
